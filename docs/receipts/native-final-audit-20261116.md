source tests establish one fresh child packet per accepted callback. Every
qualifying compound type selects once, incoming counts one/twenty do not
multiply selections, and duplicate basic choices coalesce. Several different
basic effects can therefore be submitted together. The actual-metadata scene
tests also retain six/twenty-four beam multishot controls and twenty ordinary

not evidence that every real Phantasma update produces exactly one callback.

complete receiving/application order remain separate open bindings. Existing
Monte Carlo agreement cannot close them.

handler selection retains the documented wiki eligibility fallback; it does

listed in [ENGINE_MIGRATION](../ENGINE_MIGRATION.md) and
