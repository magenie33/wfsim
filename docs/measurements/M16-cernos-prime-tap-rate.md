# M16 — Tapped bow cadence is the bow formula at zero draw

A bow's cycle is its modded draw time plus its modded nock time. A tapped
shot has zero draw, so the same formula gives:

```
tapped cycle = 0 + modded nock time
tapped rate = 1 / modded nock time
```

Cernos Prime's unmodded nock is 0.65 s: about 1.54 volleys per second.
Each volley fires three arrows. Fire-rate bonuses shorten the draw and do
not change a zero draw; reload-speed bonuses shorten the nock.

This is a consequence of the bow cadence formula, not a separate measurement
question or an in-game reading.

Source: [Fire Rate](https://wiki.warframe.com/w/Fire_Rate), bow charge formula.
