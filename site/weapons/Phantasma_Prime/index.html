WFSim for Windows

The same calculator on your own machine — it opens instantly, works with no connection, and keeps itself up to date. It is not a cut-down version: the engine is the same wasm module this site serves.

The first time you open it

  • Windows shows a blue notice, "Windows protected your PC". Click "More info", then "Run anyway".
  • It says that because this program has no code-signing certificate — one costs several thousand yuan a year, which a free tool does not justify. An antivirus warning is the same thing for the same reason: an unsigned program nobody has seen before.
  • If you would rather check first, the SHA-256 and the command to verify it ship in the notes beside the download. Or just use the site — it does everything this does.

Why install it

  • Nothing is downloaded when you open it. The engine is already on your disk, so a fight is computed the moment you ask for it — however slow this site is to reach from where you are.
  • It works with no connection at all.
  • It updates itself, and takes only what changed: a release touching one file is under a kilobyte on the wire. You download this once.
  • The site stays exactly where it is. Both run the same engine, and a build link opens in either.

What it is not

  • Not an installer. There is nothing to run as administrator, and nothing is written to the registry.
  • Not a second engine. It carries the same wasm the site serves, so a number is the same number in both.
  • Uninstalling is deleting the file. Its data sits in %LOCALAPPDATA%\WFSim and can go with it.

The source

  • AGPL-3.0. A source archive sits beside the download because the licence requires the source to be offered wherever the binary is — it is the same source that is on GitHub, and you do not need it to run the program. github.com/magenie33/wfsim

Support WFSim

A Warframe calculator that matches in-game measurements, item by item. Building, simulating and optimizing are the whole of it, and they are the same for everyone: no account, no payment, no part held back.

Why you can check it

  • Every formula in the engine cites its source — a wiki page, a datamine, or a measurement — and every golden test is calibrated against a real in-game run.
  • It tells you what it cannot model, on the card where you are standing: on a weapon, an evolution, a mod, an arcane, an enemy. It lists those itself rather than waiting to be asked.
  • Sometimes it says the number is right and the game is wrong, and names the bug a hotfix would take away.
  • And if your own in-game measurement disagrees with it, the measurement wins. That is a bug report about reality, and it is the one thing that changes what this engine does.

Where it goes

  • The wfsim.app domain, and its renewal.
  • Cloudflare — the bandwidth and build minutes that serve the app and its art from one origin, so that nothing this page needs is fetched from somewhere that might be unreachable where you are.
  • Time, which is most of it: new weapons, new mechanics, and the hours in the game that every calibrated number is measured against.

What it never buys

  • A number. Nothing bought here moves a result by one decimal — an in-game measurement is the only thing that changes what the engine does, and it wins whoever reports it.
  • A feature. Building, simulating and optimizing stay the same for everyone, and the guarantor of that is not me: this is AGPL-3.0, so the engine, the game data and the wasm are public and you can run your own.
  • A monthly subscription buys order and company, never product: a channel where the work is discussed, and your reports read before the rest of the queue. Every fix still ships to everyone at once.
  • No tracking beyond what Cloudflare counts to serve the page.
