# Caustacyst

Chinese name: 灼蚀变体镰

Scythe · Melee · Mastery Rank 7. 260 base damage (corrosive 103, impact 17, puncture 71, slash 69), 9% crit chance, 2x crit multiplier, 37% status chance.

## Not modelled here

- Power Spike's partial combo decay is a Warframe passive and is not modelled: the counter drops to zero when its timer runs out, so with that passive the number reads low.
- Not modelled: Corrosive Wave and Corrosive Pool. Of this weapon's attacks, only the swing, the slam and the heavy slam are.
- The wiki publishes no slide attack figure or duration for this weapon, so there is no slide mode.
- This weapon's heavy attack is a thrown Corrosive wave, 225 Corrosive losing 40% a second and 20% per enemy, that leaves pools of 98 Corrosive a second for 8 s, which is not modelled, so there is no heavy mode and a Tennokai window converts nothing.
