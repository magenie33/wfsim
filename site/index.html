wfsim

A hardcore Warframe damage simulator. It doesn't estimate a DPS number — it replays the fight, and its output is calibrated against in-game Simulacrum measurements.

What works today

The full damage pipeline

Mod bucket math, elemental combination order, tiered crits, status procs & DoTs, Toxin shield-bypass, armor mitigation — every formula sourced and golden-tested.

Incarnon, done right

Charge-backed alternate forms (charges aren't a magazine) and per-tier evolution search — which already exposes evolutions that are mathematically dead.

A real build optimizer

Mod pool + constraints in; Monte-Carlo successive elimination across all cores; a ranked top-10 out, each loadable back into the sim. It only ever calls the engine — no side-formulas.

Local web UI

Build configurator, per-buff stack/lock controls, sim panel and optimizer with savable scope presets. Rust, open source, MIT.

On the roadmap: more weapons, multiple enemies in a 2D arena (so range, AoE and punch-through payoffs are modeled properly), Rivens, and an in-browser (WASM) version of the engine on this very page.
