WFSim for Windows

The same calculator on your own machine: it opens instantly, works offline and updates itself.

The first time you open it

  • Windows shows a blue notice, "Windows protected your PC". Click "More info", then "Run anyway".
  • The program is not code-signed, which is also why an antivirus may warn about it.
  • The SHA-256 and the command to verify it are in the notes beside the download.

What it does

  • It runs the same wasm engine as the site, so every number matches.
  • The engine is on your disk, so a fight is computed the moment you ask for it.
  • It works with no connection at all.
  • It updates itself, downloading only what changed.

Install and uninstall

  • No installer: it needs no administrator rights and writes nothing to the registry.
  • To uninstall, delete the file. Its data is in %LOCALAPPDATA%\WFSim.

The source

  • AGPL-3.0. The source archive beside the download is the same source as on GitHub. github.com/magenie33/wfsim

The fight

Support WFSim

The Warframe calculator that matches the game, measured item by item. The calculator is free for everyone, and the same for everyone.

It does not score an opening state. It runs the fight — every ramp, every reload, every status that had to land before the damage depending on it — and reports what happened.

How it works

  • How much of a grenade's damage was the impact and how much was the cloud it left behind is something the fight works out. It is not a ratio you type in.
  • A mod that stacks on kill starts the fight at zero stacks. It builds during the fight, expires, and decays — so the build's own numbers change while you are shooting.
  • How many Forma a build needs is computed, and so is whether it fits in the weapon at all.

How to check it

  • Every formula in the engine cites its source — a wiki page, a datamine, or a measurement — and every golden test is calibrated against a real in-game run.
  • What it cannot model is stated on the card concerned: a weapon, an evolution, a mod, an arcane, an enemy.
  • Sometimes it says the number is right and the game is wrong, and names the bug a hotfix would take away.
  • Where your in-game measurement disagrees with it, the measurement wins.

The calculator is the same for everyone

  • Building, simulating and optimizing are the same for everyone. This is AGPL-3.0: the engine, the game data and the wasm are public, and you can run your own copy.
  • What you have run here stays in your own browser. What the site counts, and how to turn it off, is at the foot of this page.

What is counted

WFSim counts what gets used — which pages open, whether a build was computed, a simulation or a search started and finished, whether Nona was opened, asked something or set to concise mode (never what was asked), whether the page itself failed (the kind of failure and where in WFSim's own code, never its text), a board build opened, a link shared and from which part of the page, how many presets and customs are saved — under a random id this browser keeps. The count records no IP address and sets no cookie, and the id is not linked to anything that identifies you. With Global Privacy Control or Do Not Track on, nothing is sent. Per weapon, how many people ran a simulation or a search each day is added up and shown on the home page as its popularity ranking — totals only.

It also counts what kind of device opens it, in broad classes only — touch or mouse, a narrow or wide screen, how many processor cores in a few steps, whether it is inside WeChat or QQ — never the model or the browser, and whether computing for the board carries on with the page out of sight.
